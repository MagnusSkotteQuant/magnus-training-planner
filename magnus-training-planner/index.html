Simple, local planning

Normal workout edits save automatically in this browser. No GitHub upload is needed when your schedule changes.

  1. Open Share & backup and copy a week link, or export the plan as JSON.
  2. Your coach opens the link, edits sessions and comments, and sends a fresh link or export back.
  3. Review the shared plan, then choose Save to this device. JSON imports ask before merging.

There is no live sync between people, browsers, or devices. Clearing browser data removes local plans, so keep JSON backups. Links are snapshots, not private invitations.

On a phone, use the Day field in the workout editor to move sessions. Print / PDF includes the current week's details and notes.
